# Product Flow

## 최신 기본 흐름

```text
로그인
  -> 홈
      -> 일일 미션
      -> 학습
      -> 배틀
      -> 랭킹/승급전
      -> 하우징
      -> 상점
      -> 가챠
```

### 보상 루프

- 일일 미션 -> 복습 문제 -> 제출 -> 채점 -> 개별/올클리어 보상
- 학습 -> 문제 선택 -> 코드 작성 -> 제출 -> 채점 -> 정답 보상
- 배틀 -> 방 참가 -> Ready -> 게임 시작 -> 문제 풀이 -> 점수 경쟁 -> 결과 보상
- 랭킹/승급전 -> 랭킹 확인 -> 승급전 -> 문제 풀이 -> 성공 시 보상

위 보상은 재화 획득으로 연결됩니다.

### 소비/수집 루프

```text
재화
  -> 상점 -> 가구 구매 -> 하우징
  -> 가챠 -> 고양이 획득 -> 하우징
```

### 하우징

- 가구 배치
- 고양이 상호작용

## 확정된 시작 규칙

- 플레이 시작 시 기본 주황 고양이 1마리를 보장합니다.
- DB 사용자에게는 `cat_id=1` 스타터를 중복 없이 보장합니다.
- 아직 확정되지 않은 가챠 확률/비용, 최종 경제 수치, 최대 하우스 배치 마릿수는 이 문서에서 임의 확정하지 않습니다.
