# 학습용 고양이 게임 구현 로드맵

이 문서는 프로젝트의 전체 구현 체크리스트와 현재 진행 지점을 저장소에 남기기 위한 기준 문서다.

## 상태 기준

- `[x]` 완료 및 현재 브랜치에서 확인됨
- `[ ]` 미완료 또는 기존 구현을 다시 검증해야 함
- `부분 구현`은 코드가 일부 존재하더라도 해당 항목의 완료 조건을 모두 검증하지 않은 상태

현재 작업 브랜치: `feature/db-schema`

현재 재개 지점: **5-4. 채점용 Docker 이미지 작성**

> 기존 저장소에는 뒤 단계의 API와 기본 로직이 일부 존재한다. 그러나 이 로드맵에서는 실제 코드, ORM, API 명세, 테스트가 함께 검증되기 전까지 완료로 표시하지 않는다.

# 작업 재개 규칙

1. 가장 위의 미완료 항목부터 시작한다.
2. 작업 전 현재 코드와 미커밋 변경사항을 확인한다.
3. 기존 구현이 있어도 ORM, API 계약, 오류 처리 및 테스트를 모두 확인한다.
4. Backend 변경 시 `docs/api/api-spec.md`에 Frontend 사용 규칙도 함께 기록한다.
5. DB 구조 변경 시 새 Alembic migration을 추가하고 기존 migration을 임의로 수정하지 않는다.
6. 기능 완료 후 관련 테스트와 `git diff --check`를 실행한다.
7. 검증이 끝난 항목만 `[x]`로 변경한다.
8. 커밋과 push는 변경 요약을 먼저 확인한 뒤 실행한다.
