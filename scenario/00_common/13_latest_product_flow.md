# 최신 전체 서비스 흐름 기준

이 문서는 2026-08-27에 정리된 최신 흐름도를 기준으로 시나리오 문서의 상위 연결 관계를 정리한다.

## 핵심 흐름

```text
로그인
  ↓
 홈
  ├─ 학습 → 문제 선택 → 코드 작성 → 제출 → 채점 → 정답 보상
  ├─ 배틀 → 방 참가 → Ready → 게임 시작 → 문제 풀이 → 점수 경쟁 → 배틀 결과 보상
  ├─ 랭킹/승급전 → 랭킹 확인 → 승급전 도전 → 문제 풀이 → 성공/실패
  │                                         ├─ 성공 → 승급 성공 보상
  │                                         └─ 실패 → 종료
  │
  └─ 상점 / 가챠 / 하우징으로 직접 이동 가능

정답 보상 / 배틀 결과 보상 / 승급 성공 보상
  ↓
재화 획득
  ├─ 상점 → 가구 구매 → 하우징 적용
  └─ 가챠 → 고양이 획득 → 하우징 배치

하우징
  ├─ 가구 배치
  └─ 고양이 상호작용
```

## 이 흐름에서 중요한 설계 해석

1. 학습, 배틀, 승급전은 재화를 얻는 `생산 루프`다.
2. 상점과 가챠는 모은 재화를 사용하는 `소비 루프`다.
3. 하우징은 소비 결과가 눈에 보이게 누적되는 `보상 공간`이다.
4. 학습 실패, 배틀 패배, 승급전 실패가 어떤 보상을 받는지는 별도 비즈니스 규칙으로 확정한다.
5. 홈에서는 상점/가챠/하우징에 직접 접근할 수 있다. 재화가 없으면 구매/뽑기만 실패한다.
6. 출석은 메인 흐름도에 큰 메뉴로 넣기보다 로그인 또는 홈 진입 시 별도 보상 흐름으로 처리할 수 있다.
7. 방 생성, 회원가입처럼 대표 흐름도에 보이지 않는 기능도 상세 시나리오에서는 유지한다.

## 시나리오 폴더와 연결

- 학습: `01_learning_grading/`
- 가챠: `02_gacha/`
- 배틀: `03_battle/`
- 승급전: `04_rank_challenge/`
- 로그인/회원가입: `05_auth/`
- 하우징: `06_housing/`
- 상점: `07_shop/`
- 출석: `08_attendance/`

앞으로 새로운 시나리오를 추가할 때는 이 흐름을 먼저 보고, 어떤 도메인에서 재화가 생성되고 어디서 소비되는지까지 연결해서 작성한다.
