# 코딩 전에 결정해야 하는 비즈니스 규칙 체크리스트

이 문서는 개발자가 자기 판단으로 숫자나 정책을 코드에 박아 넣는 일을 막기 위한 체크리스트다.

## A. 학습·채점

- [ ] `TASK_ATTEMPTS.status` 최종 상태값을 무엇으로 할지 확정
  - 후보: `PENDING`, `RUNNING`, `PASSED`, `WRONG_ANSWER`, `RUNTIME_ERROR`, `TIMEOUT`, `SYSTEM_ERROR`
- [ ] 오답도 모든 시도를 DB에 남길지 확정
- [ ] 재제출 횟수 제한 여부 확정
- [ ] 힌트 사용 시 보상 감소 여부 확정
- [ ] 최초 정답 보상량 확정
- [ ] 같은 문제 재정답 시 보상 0원인지 확정
- [ ] 숙련도 증가/감소 규칙 확정
- [ ] `TASKS.test_cases` 저장 형식 확정
- [ ] 실행 제한시간 확정
- [ ] 채점 결과 메시지를 DB에 저장할지 확정
- [ ] 오래된 PENDING을 자동 오류 처리할지 확정

## B. 가챠

- [ ] 1회 가격
- [ ] 다회 가격
- [ ] 10회인지 10+1인지
- [ ] 희귀도 단계
- [ ] 각 희귀도 확률
- [ ] 중복 고양이 허용 여부
- [ ] 중복 시 mileage 전환 여부
- [ ] mileage 지급량
- [ ] 천장 유무
- [ ] 천장이 있다면 누적 횟수 저장 위치
- [ ] 가챠 결과를 별도 이력으로 남길 필요가 있는지

## C. 배틀

- [ ] 방 생성 시 방장을 자동 참가자로 넣을지
- [ ] 최소 시작 인원
- [ ] 방장도 Ready를 눌러야 하는지
- [ ] 전원 Ready가 필요한지
- [ ] 개인전/팀전 지원 범위
- [ ] 정답 점수
- [ ] 오답 감점 여부
- [ ] 속도 보너스 여부
- [ ] 문제 재도전 가능 여부
- [ ] 배틀 종료 조건
- [ ] 동점 처리
- [ ] 중도 이탈 처리
- [ ] 재접속 허용 시간
- [ ] 승자 보상 여부

## D. 승급전

- [ ] 한 번에 출제되는 문제 수
- [ ] 전체 제한시간
- [ ] 합격 기준
- [ ] 실패 시 랭크 점수 감소 여부
- [ ] 성공 시 점수 증가량
- [ ] 도전 쿨타임
- [ ] 진행 중 재접속 허용 여부
- [ ] 만료 직전 제출 처리 기준
- [ ] 이미 통과한 문제 재제출 허용 여부

## E. 인증

- [ ] 아이디+비밀번호인지 소셜 로그인인지
- [ ] username UNIQUE 여부
- [ ] 이메일 컬럼 필요 여부
- [ ] password_hash 컬럼 추가 여부
- [ ] access token 만료시간
- [ ] refresh token 사용 여부
- [ ] refresh token 저장 위치
- [ ] role 기본값
- [ ] 탈퇴 사용자 처리 방식

## F. 하우징

- [ ] 좌표 형식 (`x`, `y`, `rotation`) 확정
- [ ] 격자 크기
- [ ] 좌표 허용 범위
- [ ] 회전 각도 단위
- [ ] 가구 겹침 허용 여부
- [ ] 벽지/바닥 category 명칭
- [ ] house_level의 실제 기능
- [ ] 다른 사용자 하우스 방문을 MVP에 포함할지

## G. 상점

- [ ] 판매 가능한 item category 목록
- [ ] 구매 수량을 1개씩만 허용할지
- [ ] 품절/판매중지 개념이 필요한지
- [ ] 환불 기능이 필요한지
- [ ] 가격 변경 시 기존 구매 기록이 필요한지

## H. 출석

- [ ] 출석 보상량
- [ ] 첫 로그인 자동 출석인지 버튼 방식인지
- [ ] 날짜 기준 timezone
- [ ] 연속 출석 추가 보상이 있는지
- [ ] streak 최대 보너스가 있는지

## 공통 규칙

- [ ] API prefix를 `/api/v1`로 통일할지
- [ ] 성공/실패 Response 공통 형태를 만들지
- [ ] 서버 시간은 UTC 저장 후 사용자 timezone으로 표시할지
- [ ] 삭제 정책: hard delete / soft delete
- [ ] 운영자/관리자 기능을 어느 범위까지 넣을지

이 문서에서 체크되지 않은 항목은 코드에 상수로 박지 않는 것을 원칙으로 한다.
