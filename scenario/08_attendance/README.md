# 08. 출석

이 폴더는 **매일 자정 이후 첫 로그인 시 자동으로 출석을 처리하고 100원을 지급하는 흐름**을 설명합니다.

주요 내용은 다음과 같습니다.

- 자정 이후 첫 로그인 시 자동 출석
- 기본 출석 보상 100원
- 연속 출석 streak 계산
- 연속 출석이 끊긴 경우 초기화
- 같은 날 재로그인/중복 처리 방어
- 동시에 여러 번 출석 로직이 실행되는 경우 처리
- 출석 보상 지급
- 출석 처리 중 오류 발생 시 트랜잭션 롤백
- 출석 기록 조회
- 자정 경계 처리
- 서버 기준 날짜 사용

주요 테이블: `USERS`, `ATTENDANCES`

핵심 방어 방법은 `(user_id, check_in_date)` 복합 UNIQUE 제약입니다. 같은 날 여러 번 로그인하거나 중복 요청이 발생해도 출석 행과 보상은 한 번만 성공해야 합니다.

현재 남은 주요 기획 결정은 **어느 timezone의 자정을 서비스 기준으로 사용할지**입니다. 날짜 판정은 클라이언트 시간이 아니라 서버가 수행합니다.
