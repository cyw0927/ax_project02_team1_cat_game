# 08. 출석

이 폴더는 사용자가 하루 한 번 출석 체크를 하고 연속 출석과 보상을 처리하는 흐름을 설명합니다.

주요 내용은 다음과 같습니다.

- 오늘 첫 출석
- 연속 출석 streak 계산
- 연속 출석이 끊긴 경우 초기화
- 당일 중복 출석 방어
- 동시에 여러 번 출석 요청이 들어오는 경우 처리
- 출석 보상 지급
- 출석 처리 중 오류 발생 시 트랜잭션 롤백
- 출석 기록 조회
- 자정 경계 처리
- 서버 기준 날짜 사용

주요 테이블: `USERS`, `ATTENDANCES`

핵심 방어 방법은 `(user_id, check_in_date)` 복합 UNIQUE 제약입니다. 중복 요청은 DB가 `IntegrityError`를 발생시키도록 하고 백엔드가 이를 처리합니다.
