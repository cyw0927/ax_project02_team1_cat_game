# 06. 하우징

이 폴더는 사용자가 보유한 아이템으로 자신의 하우스를 꾸미는 흐름을 설명합니다.

주요 내용은 다음과 같습니다.

- 하우스 조회
- 보유 가구 조회
- 가구 배치
- 보유 수량보다 많이 배치하는 요청 방어
- 가구 이동
- 가구 회전
- 가구 치우기
- 벽지 적용
- 바닥 적용
- 다른 사용자의 하우스 읽기 전용 방문

주요 테이블: `USERS`, `ITEMS`, `INVENTORIES`, `PLACED_OBJECTS`

격자 크기, 좌표 허용 범위, 회전 단위, 가구 겹침 허용 여부, house_level의 역할은 아직 확정되지 않았습니다.
