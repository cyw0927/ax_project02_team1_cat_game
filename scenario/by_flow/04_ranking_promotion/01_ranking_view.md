# 01. 랭킹 확인

## 목적
사용자가 현재 랭킹 그룹, 본인 점수, 순위, 승급전 도전 가능 여부를 확인하는 단계다.

## 정상 흐름
1. 홈에서 `랭킹/승급전` 진입.
2. 서버가 사용자의 랭킹 그룹을 확인한다.
3. 그룹 참가자와 `current_rank_score`를 조회한다.
4. 서버 기준으로 본인 순위와 현재 도전 상태를 계산한다.
5. 화면에 순위, 점수, 진행 중 승급전 여부, 도전 버튼 상태를 표시한다.

## 발생 가능한 변수
### A. 랭킹 그룹이 없음
- 원인: 신규 사용자, 배정 로직 미실행, 데이터 누락.
- 감지: 사용자에 연결된 ranking group/participant가 없음.
- 해결: `순위 없음` 상태로 표시하고 자동 배정 정책이 확정되지 않았다면 임의 생성하지 않는다.
- UI: `아직 랭킹 그룹에 배정되지 않았습니다.`

### B. 그룹은 있으나 참가 row가 없음
- 원인: 일부 생성 실패, 데이터 마이그레이션 누락.
- 해결: 조회 실패와 정상 미배정 상태를 구분하고 서버 로그로 추적한다.

### C. 동점자가 여러 명
- 원인: 동일한 `current_rank_score`.
- 해결: 동점 정렬 기준은 `TBD`. 임의로 가입일/ID 순 정렬을 정책으로 확정하지 않는다.

### D. 화면 점수가 오래됨
- 원인: 다른 기능에서 점수 변동, 다른 기기 사용.
- 해결: 서버 응답을 권위 상태로 사용하고 화면 진입/새로고침 시 재조회한다.

### E. 랭킹 목록이 매우 큼
- 원인: 참가자 수 증가.
- 해결: pagination/cursor 도입을 검토하되 현재 정책 미확정이면 문서에서 방식 고정 금지.

## DB/API 영향

- 진행 중 RANK_CHALLENGES 존재 여부
