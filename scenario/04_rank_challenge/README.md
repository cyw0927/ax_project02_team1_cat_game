# 04. 랭킹·승급전

이 폴더는 사용자가 소규모 랭킹 그룹에 참여하고 승급전에 도전하는 흐름을 설명합니다.

주요 내용은 다음과 같습니다.

- 랭킹 그룹 조회
- 참가자 점수와 순위 조회
- 승급전 시작
- 진행 중 승급전 중복 방어
- 승급전 문제 생성
- 작성 중 코드 자동 저장
- 네트워크 단절 후 이어하기
- `expires_at` 기준 제한시간 판정
- 문제 통과 처리
- 승급 성공·실패·시간초과 및 점수 반영

주요 테이블: `RANKING_GROUPS`, `RANKING_PARTICIPANTS`, `RANK_CHALLENGES`, `RANK_CHALLENGE_TASKS`, `TASKS`

문제 수, 제한시간, 합격 조건, 성공/실패 시 점수 변화는 아직 확정되지 않았습니다.
