# 핵심 테스트케이스 매트릭스

모든 시나리오를 자동화할 필요는 없지만, 실패하면 큰 문제가 생기는 기능은 아래 항목을 우선 검증한다.

## 학습·채점

| ID | 테스트 | 기대 결과 |
|---|---|---|
| T-A01 | 활성 문제 조회 | 200, test_cases 비노출 |
| T-A02 | 없는 문제 제출 | 404 |
| T-A03 | 정상 제출 | TASK_ATTEMPTS PENDING, 202 |

| T-A05 | 오답 코드 | WRONG_ANSWER |

## 테스트 우선순위

1. 재화 복제 가능성이 있는 상점/가챠/출석/최초 정답 보상
2. Docker 자원 제한과 TIMEOUT
3. 방 정원 같은 동시성
4. 승급전 만료시간
5. 인증/소유권
6. 단순 조회

테스트 이름은 실제 pytest 작성 시 `test_<기능>_<조건>_<기대결과>`처럼 읽히게 작성한다.
