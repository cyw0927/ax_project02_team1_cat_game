# 02. 가챠

이 폴더는 사용자가 재화를 사용해 고양이를 뽑고 결과를 소유 데이터에 반영하는 흐름을 설명합니다.

주요 내용은 다음과 같습니다.

- 1회 뽑기와 다회 뽑기
- 재화 차감
- 희귀도 확률 적용
- 획득 고양이 저장
- 중복 고양이 처리
- mileage 전환 여부
- 천장 정책 여부
- 버튼 연타와 동시 요청 방어
- 처리 도중 오류 발생 시 트랜잭션 롤백

주요 테이블: `USERS`, `CATS`, `USER_CATS`

아직 가격, 확률, 중복 처리, 천장 정책은 확정되지 않았으므로 임의로 정하지 않습니다.
