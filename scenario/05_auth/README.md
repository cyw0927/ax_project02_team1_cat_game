# 05. 로그인·회원가입·인증

이 폴더는 사용자가 계정을 만들고 로그인한 뒤, JWT 등 인증 정보를 이용해 본인 권한으로 API를 호출하는 흐름을 설명합니다.

주요 내용은 다음과 같습니다.

- 회원가입
- 아이디 중복 확인
- 비밀번호 저장 방식
- 로그인
- Access Token 발급
- Token 만료와 재로그인/재발급
- Request body의 `user_id` 의존 제거
- 현재 로그인 사용자 식별
- 로그아웃
- role 기반 권한 제한

주요 테이블: `USERS`

현재 ERD에는 비밀번호 또는 소셜 로그인 식별자 컬럼이 없으므로 실제 구현 전에 가입 방식과 인증 데이터 구조를 확정해야 합니다.
