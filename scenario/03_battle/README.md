# 03. 실시간 배틀

이 폴더는 사용자가 배틀방을 만들거나 참가하고, 준비 상태를 맞춘 뒤 동일한 문제를 풀며 점수를 경쟁하는 흐름을 설명합니다.

주요 내용은 다음과 같습니다.

- 방 목록 조회와 방 생성
- 방 참가
- 정원 초과 방어
- `SELECT ... FOR UPDATE`를 이용한 동시 입장 제어
- 준비 상태 변경
- 방장 시작 권한
- 배틀 문제 진행
- 정답에 따른 점수 반영
- WebSocket 기반 실시간 점수 갱신
- 종료 조건, 승자 계산, 중도 이탈 처리

주요 테이블: `ROOMS`, `ROOM_PARTICIPANTS`, `ROOM_TASKS`, `TASKS`, `USERS`

최소 인원, Ready 조건, 점수 규칙, 동점/이탈/보상 정책은 아직 확정되지 않았습니다.
